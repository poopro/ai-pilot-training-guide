# 停止目前訓練並取得成績

目前這次訓練使用 `E:\ai_pilot\2026 AI 飛行員  相關資料\AI空戰競賽系統安裝及測試指引\AI空戰競賽系統安裝及測試指引\AirCombat_Train_Test`。

## 1. 停止並儲存

1. 找到正在跳出 `time/`、`train/` 表格的訓練視窗。
2. 用滑鼠點一下視窗內，按 **Ctrl+C 一次**。
3. 等它完成儲存並回到命令提示字元。儲存 replay buffer 可能需要幾分鐘。請勿連按 Ctrl+C 或直接按右上角 X。
4. 用檔案總管開啟上述 `AirCombat_Train_Test\models`，確認 `jsbsim_sac.zip` 與 `jsbsim_sac_buffer.pkl` 都存在，而且檔案大小大於 0。前者是模型，後者是訓練經驗。
5. 如果停止時出錯，`AirCombat_Train_Test\model` 裡原本的 `jsbsim_sac_..._steps.zip` 仍是可使用的定期模型。另外在 `models\backup_2026-10-02` 有停機前備份的 4,960 萬步模型、訓練程式與 TensorBoard 紀錄。

## 2. 取得目前能測量的數字

訓練視窗停止後，雙擊本資料夾的 `評估目前模型.cmd`。它會自動找最新模型，跑 5 回合，並在 `AirCombat_Train_Test\eval_reports` 產生 CSV 和 JSON。

- `mean_episode_reward`：完成回合的平均獎勵。這是目前簡化環境的分數，不是比賽分數。
- `survival_rate`：五回合裡，我方沒有墜機的比例。
- `attack_window_seconds`：每回合位於鼻軸 2 度內、距離 500 至 3000 呎的累積秒數。這是幾何條件的估計。
- `attack_3s_proxy`：上述條件累積達 3 秒的估計結果。它不是官方擊殺。
- `end_reason`：我方墜機、敵機自行墜機、五分鐘到時，或評估提早截止。
- `failure_reason`：若我方墜機或評估未完成，顯示原因；其餘顯示「無」。

五回合只能做快速檢查；正式比較兩個模型時，建議各跑至少 20 回合，並使用相同測試條件。

## 3. 真正的成功率／擊殺率

目前的訓練環境沒有實作命中或擊殺事件，因此無法從這次訓練的 loss 或 TensorBoard 讀出真實擊殺率。需要載入這個模型並用主辦方 Host 測試：先啟動 Player1 連線程式，再啟動 Host，按 INIT、等雙方 READY、按 START。每回合結束後等 Host 存好 CSV / ACMI，再記錄勝負、擊殺與存活。Host 的詳細按鍵流程在 `D.比賽用主辦方連線程式_驗證是否符合能正確連線\readme_part1.txt`。

注意：官方範例 `player1_Loadmodel.py` 目前仍指向隨附的舊模型；正式 Host 測試前，要把其中的 `MODEL_PATH` 指到這次新儲存的模型，且先確認 26 個輸入資料與模型預期的狀態轉換相容。
