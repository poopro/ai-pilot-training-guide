# AI 飛行員競賽進度報告(2026-10-21)

> 資料更新到 2026-10-20 傍晚。所有勝率都來自作者自己的本地模擬器與本地 judge,不是主辦方認證的結果,也不代表對其他隊伍的勝率。這份公開報告刻意不含私有 IP、個資、報名資料、控制程式原始碼,以及針對特定對手類型的細節。

## 一句話現況

單人參賽,目標是 2026 AI 空戰競賽(11/7–11/8,1v1 F-16,BO3 淘汰)。目前的主力是「官方範例追擊程式 + 防撞盾 + 自動調參」的規則式飛行員,本地測試表現最好;所有更複雜的學習式方法都沒有贏過它。對真實對手(其他隊的 AI)的強度仍然未知。

## 目前的系統

| 層 | 內容 | 狀態 |
| --- | --- | --- |
| 飛行員本體 | 官方範例的追擊程式,把機鼻對準對手 | 凍結,當保底 |
| 防撞盾 | 規則寫死的保護:快撞、太低、G 太大時強制閃避 | 已完成並驗證 |
| 調參補丁 | 用演化策略自動調出較好的追擊常數,共兩輪 | 第二輪完成,目前的預設版本 |
| 可攜式 Player 套件 | 疊在官方軟體上,不修改官方檔案;可用開關選版本 | 已驗證與研究版行為一致 |
| 選配:果蠅連結體戰術選擇器 | 近距離時由剪枝後的連結體模擬挑戰術,出錯或太慢時自動退回預設版本 | 通過非劣性測試,仍屬選配 |

## 已驗證的

- **本地勝率:** 預設版本在 264 場配對測試中贏 245 場(93%);前一輪調參版 213 勝、只加防撞盾的版本 200 勝(同一批開局)。測試中 0 碰撞、0 超 G。
- **官方 Host 連線測試 #1:** 三個版本各跑一輪,全程狀態有效、無效觀測 0 筆、回傳頻率約 60 Hz;最小機間距 595–691 公尺(撞機線 15 公尺)、最低高度約 4930 公尺,無碰撞、無墜毀。
- **可攜套件正確性:** 用合成觀測逐幀比對,與研究版輸出差異為 0;假 Host 的 UDP 迴路測試全數通過。
- **果蠅連結體選配版的非劣性測試:** 預先登記判準後跑 264 組配對。純預設版 241 勝 23 敗(91.3%),加選配版 250 勝 14 敗(94.7%);配對勝率差 +3.4 個百分點,95% 區間 [−0.4, +7.2];0 個錯誤;被擊落加碰撞的敗局 0 對 1。判準全部通過,因此判定為「不劣於」,**不是**「較好」的證明,區間含 0。測試中也觀察到一種對手類型下的退步,資料方向一致但統計上不顯著,細節不在公開報告中。
- **純 NumPy 移植:** 選配版在 NumPy 1.26.4、2.2.6、2.5.3 下輸出逐位元相同;每個決策平均約 6 ms、最慢約 14–18 ms,每 20 個 tick 才跑一次;連續 3 次單次超過 60 ms 就退回預設版本。

## 還沒驗證的

- 對真實對手(其他隊的 AI)的強度:完全沒有資料。
- Host 內建的測試對手只會隨機畫圈、不攻擊也不閃避,官方文件說它只用來驗證連線,所以 Host 測試只證明「連得上、不會撞」。
- Host 結果沒有明文勝負,「我方擊殺」是從 Tacview 紀錄重建的推定,和 Host 結束幀有 −22 到 +93 幀的差距。
- 對手出現在我方右側的 Host 回合、更多局數、逐筆延遲量測都還沒做。
- 本地模擬與 Host 的時間尺度是否一致、轉彎是否太溫和,目前只是假設。

## 試過但沒有上場的方向

| 方向 | 結果 |
| --- | --- |
| 強化學習殘差(SAC 疊在規則程式上) | 從沒贏過純規則版本 |
| JEPA 式預測網路(約 23.7 萬參數) | 輸給更簡單的線性戰術選擇器 |
| 軍事式前瞻規劃器與其他戰術實驗 | 沒贏過調參版 |
| 小型決策語言模型(Kev) | 單次決策延遲遠高於線性選擇器,不採用 |
| 大型語言模型逐幀控制 | 每個決策只有約 16 毫秒,做不到 |
| 果蠅連結體本身 | 把連結體打亂,表現一樣好;增益主要來自「近距離不要一直純追擊」,連結體沒有獨立貢獻 |

## 學到的三件事

1. 簡單規則加保護加自動調參,贏過所有花俏的模型;比賽開局條件很窄,直接搜尋參數比重新訓練划算。
2. 很多「進步」其實是「少做蠢事」。隨機選戰術就能拿走大部分增益。
3. 本地勝率不等於真實勝率。接下來的重點是讓陪練對手更真實,而不是再訓練新模型。

## 接下來

- 補齊官方 Host 測試:右側對手回合、更多局數、延遲量測。
- 讓陪練更真實:本地重現 Host 的測試對手並比對時間尺度,做會高 G 轉彎、會反擊的陪練。
- 11/3 23:59 凍結:之後不再訓練、不再改控制程式。
- 11/4–11/6 備份與彩排,11/7–11/8 比賽。
