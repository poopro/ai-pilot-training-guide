## 一句話
我們的規則控制器 `tuned2` 把滾轉目標硬夾在 ±72°。CMA-ES 對抗搜尋（CPU，約 10 分鐘）找到滾轉上限 81–88° 的對手，在新種子上把 tuned2 打成 0-96。把上限放寬到 80°（`tuned2w:80`，其餘參數不變）後，在預先登記的 960 局（20 種對手、24 局、配對比較）中沒有對手顯著退步，總勝場 310 → 374／480。**`tuned2w:80` 是候選，尚未做官方 Host 實測，不是預設。**

第二輪搜尋又找到 6 個 82–85° 的對手（`adv_pool/f2w80_00..05`），在新種子上把 tuned2w:80 打成 0-24。這是「轉彎包絡」的軍備競賽；單純再放寬不行（85° 在另一組測試更差）。下一步是 `tune3.py`：滾轉上限與追擊常數一起調，以最差家族為目標。

## 如何重現（在 `jepa_brain/` 執行）
```bash
# 1. 確認環境：tuned2 對 guide 應為 48-0（種子 1300000）
python eval_pool3.py eval --arms tuned2 --opponents guide --n 48 --seed0 1300000 --workers <核心數> --out runs/srv_repro

# 2. 對抗搜尋（打指定藍方；種子與 held-out 不重疊）
python adv_search.py search --blue tuned2w:80 --out runs/adv_srv1 --gens 30 --pop 16 --seed0 5400000 --workers <核心數>
python adv_search.py confirm --blue tuned2w:80 --out runs/adv_srv1 --top 8 --n 48 --seed0 5960000 --workers <核心數>

# 3. tuned3（可續跑；請用不同輸出資料夾）
python tune3.py --budget-min 720 --workers <核心數> --out runs/tune03_srv
```
注意：`common.py` 需要主辦方官方套件的路徑；若找不到會直接報錯，屬預期。
