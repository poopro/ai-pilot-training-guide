完成日期：2026-10-06（工作跨越午夜）。已實作本地對戰與新對手訓練入口，完成短程訓練／保存／續跑驗證；新十萬步主訓練尚未開始。與官方 Host 程式分開，不修改官方內建 P2、不使用 UDP。

## 使用方式

1. 雙擊 [查看P2_規則式對手.cmd](<E:/ai_pilot/autopilot/查看P2_規則式對手.cmd>)，看會追擊、近距離追蹤、受威脅時閃避及恢復飛行的規則式對手。
2. 雙擊 [查看P2_SAC對手.cmd](<E:/ai_pilot/autopilot/查看P2_SAC對手.cmd>)，看現有保存的 SAC 修正量模型控制 P2。
3. 藍色 P1 是你、紅色 P2 是對手。兩個入口各先計算本地對戰，完成後開 Tacview；這是回放，不是即時連官方比賽，也不會啟動訓練。
4. 每次獨立保存 ACMI、逐回合 report.json、lab_source.py 及來源／模型識別。新產物放在 [outputs](<E:/ai_pilot/autopilot/opponent_lab/outputs>)。

預設使用 6000 呎、同高度、340 CAS、側向分隔與反向平行航向。採用本場 Host 資料支持的保守 **1° 診斷門檻**；這不等於主辦方正式確認所有版本都使用 1°。亦可用 CLI `--attack-angle 2` 與舊設定比較。

## 實作內容

- 規則式 P2：遠處以高度受控的直接追擊進場，近處使用精準追蹤；被從後方追近時短暫做防禦轉彎，限制再次觸發頻率，避免只閃避不重新交戰。
- RL P2：載入既有 148682 步凍結 SAC 模型，從 P2 視角取得其 own20＋P1 position/velocity6，再輸出四個有限的修正量。沒有讓 P2 讀到 P1 隱藏姿態、HP、動作或未來策略。
- 雙方各有獨立飛控狀態與安全保護；P2 控制只使用規定的 26 項觀測，裁判才使用兩機真值。
- 裁判與 reward 的攻擊項均採選定的 1°／2°，不是僅修改報表文字。擊落依累積 180 tick，會中止回合。
- 現有 SAC 仍是「引導器＋學習修正」，不是純 SAC，也不是為這個新起始隊形重新訓練的強 P2。

## 已驗證與實測結果

行為／初始化測試 3 項通過：追近時會進入防禦、之後恢復追擊；1° 裁判不把 1.5° 近失誤算命中；三種距離的實際分隔、雙方 CAS 340、反向航向、合法有限輸出均通過。

同一開發種子 20264000、6000 呎、1° 下，完成各一場五分鐘實際模擬：

| 本地測試 | P1／P2 有效攻擊秒數 | P1／P2 存活 | 結果與用途 |
| --- | --- | --- | --- |
| 最初相同引導器的規則式 P2 | 0／0 | 都存活 | 暴露對稱追逐和長時間恢復，未當成成功成果 |
| 修正後的規則式 P2 | 0／0 | 都存活 | P2 本地位置優勢估計約 53591，P1 約 1720；P2 依本地估計分數獲勝，仍未擊落 P1 |
| 現有 SAC＋引導器 P2 | 0／0 | 都存活 | P2 本地優勢估計高於 P1，但沒有形成有效攻擊；未證明是強空戰模型 |

**不能把「能執行」或「位置估計分數較高」當成已學會擊殺。** 現在具備兩種可切換對手，第一場仍暴露交戰能力不足。真正的下一輪目標是讓雙方更快形成有效攻擊，並在多種子、多距離下測量，而不是把這個既有 SAC 包裝為已完成強對手。

本地沒有碰撞模型，位置計分與終局估計仍不能取代官方 Host。這一個種子已用於開發，不能當獨立保留測試。

## 後續訓練與指揮官順序

1. 規則式對手保持追擊、控距、閃避和恢復等完整能力，建立多種固定戰術版本，避免只有一種可利用的套路。
2. 新開一輪 learner 對規則式／凍結 RL 對手池訓練，固定 checkpoint 作對手，不讓 P1/P2 每個 step 同時改變。已用獨立 train_opponents.py 接入這個 lab，預設沿用舊 actor、重新建立 critic／optimizer／replay；兩個回放入口仍只做回放。訓練操作見 [現在要做什麼](<E:/ai_pilot/autopilot/現在要做什麼.md>)。
3. 定期交換 P1/P2 身分、測三種距離，用全新保留種子檢查擊落、存活、攻擊時間與失敗原因。保存來源、模型、replay；不要混用舊設定的 replay。
4. 保留表現不同的固定對手，做版本池，再研究交替自我對戰。沒有需要讓兩個 learner 同時搶同一張 GPU。
5. 最後加入慢速戰術指揮官。先做具有相同戰術選項的規則指揮官基準，再比較 Jev／本機選項模型是否提高成績。

指揮官只輸出 `intercept`、`track`、`extend`、`defend`、`recover` 等受限意圖與目標參數；底層保持 60 Hz。每 1–3 秒或事件觸發做一次背景判斷，保留最短指令持續時間，逾時／無效輸出回到規則式基準。模型選擇不是把文字直接當舵面值。

Jev 原版使用外部 API，正式比賽的封閉網路條件下不能直接沿用；後續必須有可離線執行的版本，或使用本機模型替代。這次沒有接 JEV 或呼叫 API；只追加短程流程驗證，未開始主訓練。[Jev 原始專案](https://github.com/RomanSlack/jev-drone)、[TypeSafe API](https://docs.typesafe.ai/introduction/quickstart)
