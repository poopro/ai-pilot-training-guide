待確認事項：公告對位置優勢有「總平均」描述，參考公式卻列累加；本地沿用公式累加，正式權重與算法由 Host 裁判。50 ft 離地墜機門檻取自本地訓練系統，不能宣稱已確認正式 Host 相同。控制器的 800 公尺安全門檻使用官方可觀測的海拔；本地裁判的最低高度與墜機用離地高度，兩者不同。

本輪實測發現原 FDM 初始化後的 CAS 並非設定的 340 節。候選 1 保存並退役；候選 2 在位置／姿態設定後重新設定 CAS、使用正式 reset API 回到零時間，新增真實數值測試。三種距離、三個種子的 CAS 均為 340 節，距離誤差小於 0.1 ft。340 節採官方 FDM 範例的 `ic/vc-kts`（CAS）解釋；公告中文表格對 vc／vt 的說明似乎互換，正式仍應與 Host 核對。

API 語意依 [JSBSim 初始條件](https://jsbsim-team.github.io/jsbsim/classJSBSim_1_1FGInitialCondition.html) 與 [ResetToInitialConditions](https://jsbsim-team.github.io/jsbsim/classJSBSim_1_1FGFDMExec.html)。實測結果以本輪初始化與測試檔為證，不把文件說明當成執行證據。

敵方速度方向只能估計其朝向。裁判可以用敵方真實姿態判攻擊，但部署控制器不接收這個值。本地藍色是我方、紅色是對手；正式 Host 顏色仍須核對。

本輪官方 Host 啟動時出現 SmartScreen 程序，沒有操作安全提示，也沒有取得 Host 正式裁判結果。狀態為 `pending_manual`。UDP loopback、合法指令和完整本地回合都不能替代它。
