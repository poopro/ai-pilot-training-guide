# 怎麼判斷這次是否學會

先分清楚三件事：程序跑完、策略變好、正式比賽通過。三者不能互相代替。

| 判斷 | 看什麼 | 不能用什麼代替 |
| --- | --- | --- |
| 程式有訓練 | optimizer 有更新、實際新增步數、有限的模型參數、完整存檔可以載入 | GPU 使用率、只有「已儲存」文字 |
| 策略有改善 | 同種子配對測試的存活／墜機／被擊落、擊殺、攻擊時間與回合結果 | actor loss、critic loss、entropy coefficient |
| 泛化表現 | 選定版本後的新種子保留測試，報告實際場數與區間 | 最近 100 場訓練平均、調參時一直使用的種子 |
| 官方相容 | 官方 Host 初始化、完整回合、合法控制與可核對裁判結果 | loopback、ACMI、模擬器本地估計分數 |

逐回合定義：

- **擊殺**：機鼻 2°內、500–3,000 ft 的有效時間累積達 3 秒。本地環境依公告條件判定；正式以 Host 為準。
- **本地勝利**：擊殺、敵方自行墜機，或其他終局按本地優勢公式獲勝。敵方墜機不算我方擊殺。滿時位置勝利也不表示有打中敵方。
- **存活**：終局沒有我方墜機或被擊落；提前獲勝仍算存活。
- **失敗／終止**：我方墜機、被擊落、敵方墜機、同時命中、滿時、模擬異常、人工中止分開記錄。未完成回合不加入成功率。
- **攻擊能力未達成**：五分鐘存活但攻擊零秒、或沒有達成擊殺，需要另外看距離、機鼻誤差及安全介入；不能只因存活便說學會空戰。
- **平均回合獎勵**：僅平均完整回合，reward 版本不同時分開比較。訓練獎勵不是官方比分。

本輪開發測試每類對手 5 個固定種子；SAC 在 20k／50k／100k／最後存檔配對比較。若連續兩次安全或擊殺退步便停止延長候選。沒有可靠改善就保留純引導器。

最終保留測試每類 20 場，95% 存活是目標，但 20/20 存活的 95% Wilson 區間下限仍約 84%；它不足以保證真實存活率高於 95%。遇到碰撞模型或正式比分算法未核對時，只能提出本地、有限樣本的結論。
