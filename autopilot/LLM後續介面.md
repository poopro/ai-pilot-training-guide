# 底層通過後才進行的 LLM 實驗

本輪只設計介面，不啟動 LLM。先證明底層安全、有效攻擊與官方 Host 接線可用。

LLM 每 3–5 秒非同步提出一次意圖；底層引導器／SAC 仍每個 60 Hz tick 產生合法控制。LLM 不輸出舵面或油門，也不阻塞飛控。

```json
{
  "schema": "tactical_intent_v1",
  "sequence": 18,
  "issued_sim_seconds": 62.0,
  "expires_sim_seconds": 67.0,
  "mode": "pursue",
  "target_range_m": 600,
  "preferred_speed_kts": 360
}
```

`mode` 只能是 `pursue`、`preserve_energy`、`extend`、`recover`。時間使用模擬時間。範圍 200–900 公尺、速度 280–460 knots 是初始設計約束，需另做實驗；它們不是官方新增控制欄位。只接受較新的 sequence、當下未過期、有限數字和已知欄位。JSON 解析失敗、推理逾時或資料過舊時維持最後一個仍有效的意圖；到期改回已驗證引導器。低高度／失速恢復安全層始終優先。

輸入只有允許的 26 項資料所算的摘要：距離、機鼻誤差、閉合速度、高度、速度、能量趨勢、近期交戰事件。禁止用本地裁判的敵方姿態、健康或正式比分未知值作輸入。

比較順序：固定規則狀態機 → 無 LLM 的 SAC → 同一固定測試集的 LLM 高層。分開記錄 JSON 有效率、最差延遲、逾時比例、安全備援、勝率／擊殺與攻擊時間。不得用保留測試集的失敗回饋調參後仍把它稱為獨立測試。

模型需依 RTX 3060 12 GB 的實際空閒 VRAM 和延遲實測選擇。先用小型量化模型；本輪不下載模型，也不沿用未驗證的模型名稱作推薦。
