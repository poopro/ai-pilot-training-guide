# AI 空戰修正版入口

先看 [最新結果](<E:/ai_pilot/autopilot/最新結果.md>)；完整操作方式在 [使用說明](<E:/ai_pilot/autopilot/combat_fix/使用說明.md>)。

- [觀看修正版交戰](<E:/ai_pilot/autopilot/combat_fix/觀看修正版對戰.cmd>)：藍色是你，紅色是會機動的規則式對手；模擬完自動用 Tacview 回放。
- [開始新版訓練](<E:/ai_pilot/autopilot/combat_fix/開始修正版訓練.cmd>)：最多60分鐘／新增100,000次策略決策。
- [停止並保存](<E:/ai_pilot/autopilot/combat_fix/停止修正版訓練並保存.cmd>)：等待保存完畢再離開。
- [評估最新新版模型](<E:/ai_pilot/autopilot/combat_fix/評估最新修正版模型.cmd>)：與修正版純引導器做相同開局比較。
- [接續新版訓練](<E:/ai_pilot/autopilot/combat_fix/接續修正版訓練.cmd>)：載入通過校驗的最新完整模型和 replay。
- [新版官方Host連線入口](<E:/ai_pilot/autopilot/combat_fix/連官方Host_修正版純引導器.cmd>)：先核對IP／PORT；仍需Host實測，不能用本地成績宣稱通過比賽。

這些入口指向 combat_fix。舊的兩百萬步模型與原官方部署都保留；新模型不會因訓練結束而自動替換官方部署。
